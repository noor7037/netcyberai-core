# Pilot rehearsal (supervisor, 21 Nov 2026, C534)

**Written by:** the supervisor. **For:** Noor, on his own phone and laptop. **Delivers:** the checks only a person can
do, after the scripted school day (`node scripts/pilot/school_day.mjs`) has passed three times in a row.

## Before you start

- **Android app:** GitHub → Actions → the latest "android" run on `main` → Artifacts → `netcyberai-family-debug-apk`.
  Unzip it and install the `.apk` (allow "install from this source" once).
- **Laptop:** www.netcyberai.com, signed in as the rehearsal school's principal.

## On the laptop (about 15 minutes)

1. Students: import the school's real CSV with guardian columns. The summary says "N guardians added; consent is still
   needed from each".
2. One guardian: record consent, then make a School Link code (it is shown once; write it down).
3. Teacher: mark today's attendance, set one homework, post one notice; as principal, approve the notice.
4. Exams: enter marks for one paper and publish.

## On the phone (about 15 minutes)

1. Open the Family app, Parent area → Your school → enter the code → match the child.
2. Home and Parent area show today's attendance, the homework, the notice, the marks and the timetable.
3. Ask the tutor a Class 10 maths question. The answer explains first, then solves step by step, and ends "Samajh
   aaya?". Reply "samajh nahi aaya": it re-explains the same sum another way.
4. The Ask bar: tap it, type, close the keyboard. The bar comes down, its side buttons stay, and Send works in one tap.
5. Phone Back: from a chapter it goes to the subject, from Study to Home, and only from Home does it leave the app.
6. Parent area → Learning Vault shows the question you asked.

Write down anything that looks wrong, with a screenshot. That list is the last fix round before the school.
