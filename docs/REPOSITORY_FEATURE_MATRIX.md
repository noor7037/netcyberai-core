# Repository Feature Matrix

Per the founder's 2026-09-24 handoff §10 format. ADOPT = code reuse is legally
and technically safe. ADAPT = the idea/workflow is worth building, code isn't
reusable (wrong stack, unclear/copyleft license, or reference-only by design).
REJECT = conflicts with security, architecture, product philosophy, or legal
position. Full reasoning and per-repo detail lives in
`GITHUB_REFERENCE_MINING.md` and `12_RECONSTRUCTION_INVESTIGATION.md` §6/§7 —
this table is the index, not a restatement.
