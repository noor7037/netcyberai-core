# Visibility Log (AEO / GEO manual checks)

**Why this file exists:** SEO is measurable in Search Console. AEO
(Google AI Overviews, featured snippets) and GEO (Perplexity, ChatGPT
Search, Gemini) are not measurable in any analytics tool this project
has. Without a recorded check, this pillar is unfalsifiable — work
happens, nobody can say whether it worked, and it quietly stops. See
`13_VISIBILITY_PROTOCOL.md` §7.

**No results have been entered below.** Every row in the table is
blank because no AI session can run these queries against a live
Perplexity/ChatGPT Search/Google AI Overviews/Gemini session — doing so
would mean inventing what those engines returned, which is exactly the
fabrication this entire project refuses to do. An empty table with a
date column is honest. Invented rows are not.

## How to run the check

Once a month, budget 30 minutes. Run each of the 8 queries below in
Perplexity, ChatGPT Search, Google AI Overviews, and Gemini (32 checks
total, or fewer if a query is only meaningful in some engines). For
each one, record: whether NetCyberAI was cited, its position in the
answer if cited, the exact text quoted, whether that quote is
accurate, and which competitors appeared alongside it. Add the results
as new rows — never edit or delete a past month's rows. Four data
points over four months tells you whether this is working; zero tells
you nothing, forever.

At every check, also verify nothing is being quoted inaccurately. If
an engine attributes a claim to NetCyberAI that was never made, that
is worth knowing immediately, independent of whether the citation
itself is "good news."
