## Assume the real child

Many Indian children sit in a class but read and calculate 1–3 years below it (ASER 2024: only about half of Std V
read a Std II text). Write the explanation **below** the class label, offer the same idea in a picture and a lab, and
never assume a tutor, a private phone or an English-speaking parent. Studies, exams and results are the top cause of
anxiety (Manodarpan 2022: 81%), and 28% hesitate to ask: wrong answers get a calm "here is the idea again", never shame.

## The topic flow (why each step exists)

| Step | Principle |
| --- | --- |
| retrieve | retrieval practice, daily review (Rosenshine 1) |
| hook | engage (5E) with a real Indian scene; the question it raises is answered in `close` |
| explain (plain → board) | small steps, cognitive load, concept before exam form |
| diagram / figure | dual coding; integrated labels (no split attention); the whole idea visible |
| worked + faded | worked-example effect, then fading (Rosenshine 4–5) |
| lab | explore and elaborate (5E), after the idea is named (Rosenshine: hands-on after the basics) |
| guided | guided practice with a hint, ~80% success (Rosenshine 5–7) |
| misconception | confront the alternative idea after the model is built |
| keypoints, examtip, close | consolidate; separate board rehearsal from learning; close the loop |
| check (8 → 5 drawn) | mastery with calm retry; distractors are real mistakes |
| test + 7-day card | interleaving, spacing |
