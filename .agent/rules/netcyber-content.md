# NetCyberAI content work

Whenever you are asked to write, build, upgrade, review or plan NetCyberAI learning content (a chapter, subject, class,
topic, lab, diagram, question set or image plan), load and follow the skill `skills/netcyber-content/SKILL.md` in full.
Write only inside `content-inbox/` (and new files in `labs/templates/`). Never run git. Never stop a queued run before
`node skills/netcyber-content/scripts/queue.mjs status` says it is complete.
